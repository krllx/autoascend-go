# Porting AutoAscend (Python) to Go: rules

Source: the `autoascend/` package of AutoAscend (https://github.com/maciej-sypetkowski/autoascend), as shipped in
the NetHackers arena bot (read-only).
Target: the packages of `gobot` (map: `ARCHITECTURE.md`). The port was first written as one package `aa` with
goroutines and closures (tag `v0-literal-port`), then rebuilt on explicit frames and split into layers; the
rules below still hold for every line.

The goal is **action-for-action equivalence** with the Python bot on the same game seeds: the Go bot must
send exactly the same key sequence. So the port is literal, not idiomatic: same order of operations, same
branches, same bugs. Do not "fix" anything, do not simplify logic, do not reorder calls. If Python would
raise an exception in some situation, Go must panic in the same situation (see Exceptions).

## Infrastructure

- `internal/pyrt`: exceptions (`Assert(cond, args...)` for `assert`; `Raise("KeyError", fmt, ...)` for other
  Python errors; `Panic(fmt, ...)` for `raise AgentPanic(...)`), `PySet` (CPython set iteration order for ints
  `IntKey` and int pairs `PairKey`), `OMap` (insertion-ordered dict; `GetOrInsert`, `MustGet`, `Del`),
  `FloorDiv/FloorMod/FloorDivF/Div`, `PyMaxF/PyMinF`, `PyStrip`, `PySplit`, `FindAll`, `Search`, `Index`,
  `Contains`, `PyIdx`, `Sign`, `Abs`, `B2i`; numpy `RandomState` (`RandInt(lo, hi)`, `RandInt1(hi)`,
  `ShuffleLen`, `ChoiceP`).
- `grid`: `BoolGrid/I16Grid/I32Grid/F32Grid/F64Grid` = `[21][79]T` value arrays (assignment copies, like
  `.copy()`), `Pos{Y,X}`, `Nonzero` (row-major, = `zip(*m.nonzero())`), `And/Or/AndNot/Not/Any/All/Count`,
  `TranslateB/TranslateI16`, `BFS`, `BFSFlat`, `Dilate`, `Adjacent`, `CalcDPS`.
- `nle`: `GSet` glyph sets, `Isin`, `AnyIn`, `G_*` glyph sets, `GlyphIs*`, `MON_*`, `SHOP_*`, `Hunger_*`,
  `WEA_ExpectedDamage`, `PyInt`; `O_FromName(name, category)` (category -1 = None), `O_FromName1(name)`,
  `O_PossibilitiesFromGlyph`, `O_PossibleGlyphsFromObject`, `O_DescToGlyphs`, `O_GetCategory`,
  `ObjLess`/`SortObjs` (= `sorted(objs)`), `ObjClassOf`; `Obs` and its wire format.
- `nle/nhdata_gen.go` (generated by `tools/gen_go.py`): constants and tables. `Objects[i]` are `*Obj` (fields =
  union of all namedtuple fields; `Kind` = namedtuple type, e.g. `isinstance(o, O.Weapon)` -> `o.Kind ==
  KWeapon`; `o.name is None` -> `o.NameNone`). `Permonsts[i]` (`mlet` is a byte: `ord(permonst.mlet)` ->
  `int(p.Mlet)`). `ObjClasses[i]` (`nh.objclass(i).oc_class` and `nh.objdescr.from_idx(i).oc_name/oc_descr`).

## Naming

- `nh.X` -> `NH_X` (e.g. `nh.COIN_CLASS` -> `NH_COIN_CLASS`, `nh.GLYPH_MON_OFF` -> `NH_GLYPH_MON_OFF`).
- `O.X` constant -> `O_X` (`O.ARM_SUIT` -> `O_ARM_SUIT`, `O.P_DAGGER` -> `O_P_DAGGER`).
- `MON.M2_WERE` -> `MON_M2_WERE`, `MON.S_MIMIC` -> `MON_S_MIMIC`. `SS.S_web` -> `SS_S_web`. `G.TRAPS` -> `G_TRAPS`.
- `A.Command.ESC` -> `A_Command_ESC`, `A.MiscAction.MORE` -> `A_MiscAction_MORE`, `A.TextCharacters.SPACE`,
  `A.CompassDirection.N`, `A.MiscDirection.WAIT` likewise. A one-char string action `'y'` -> `Ch('y')`.
- Classes/methods: snake_case -> CamelCase (`get_best_melee_weapon` -> `GetBestMeleeWeapon`), private
  `_foo` -> `foo`. Class constants: `Item.CURSED` -> `Item_CURSED`, `Character.MONK` -> `Character_MONK`,
  `Level.SOKOBAN` -> `Level_SOKOBAN`.
- Keyword/default arguments become explicit positional parameters (or an options struct); callers pass the
  Python defaults explicitly.
- Keep the signatures already declared in the skeleton files; other ports call them. You may add fields and
  private helpers. If you need something from another module that is not declared, read its Python source and
  call the Go name that follows these rules; list such assumptions in your final report.

## Generators, strategies, context managers

A strategy generator becomes a node (`Check` = the code up to the yield, the rest a frame); a generator passed
to `agent.step(action, gen())` becomes a dialog frame; `with atom_operation()` is `sense.Atom(body)`, `with
panic_if_position_changes()` is `flow.PosGuard(body)`. How to write them: `ARCHITECTURE.md`, "Frames, nodes,
conditions". When a yield sits inside a loop with the `yielded` flag pattern, use `flow.Loop` / `flow.LoopFrom`
with a `Stepper` (one iteration per call) and check every path.

## Exceptions

Python exceptions are Go panics. `assert` -> `Assert`. Errors Python would raise implicitly must be raised
too when the Python code can hit them: `d[k]` on a missing key -> `MustGet`; `list.index` miss -> `Index`;
`int('x')` -> `PyInt`; division by zero -> `Div`/`FloorDiv`; `next(iter([]))` -> StopIteration; unpacking
mismatches; `min([])`/`max([])` -> ValueError. `except X:` blocks -> a frame's `Catch` (or `pyrt.Try` inside plain code), re-raise otherwise.
Go runtime errors (nil deref, index out of range) count as "any other exception", which is fine where Python
would also fail. Python negative indexing (`a[-1]`, `arr[y-1]` with y=0) silently wraps: reproduce that where
it can happen (use `PyIdx`).

## Data structures

- Python dict iteration = insertion order: use `OMap` or slices whenever a dict is iterated or its order is
  observable. Go maps only for pure lookups.
- Python set iteration order: use `PySet` when a set of ints/int-pairs is iterated or converted to a list;
  for pure membership tests any Go structure is fine. Sets of objects/items used only for membership: plain maps.
- `sorted`/`list.sort` are stable -> `sort.SliceStable`. `min`/`max` return the first extreme element.
  `max(actions, key=...)` -> first max.
- numpy arrays of the map are `[21][79]` Go arrays. Watch dtypes: numpy float32 arithmetic must be done in
  float32 where numpy does it (in-place ops on a float32 array compute in float64 when the other operand is an
  int32/int64 array or float64, then round to float32). `np.sum` on bool -> count. numpy int arrays wrap
  silently only on overflow (never happens here).
- Python ints vs floats: `/` is float division, `//` floor division (FloorDiv), `%` floor mod (FloorMod).
  Item weights are float64 (`Obj.Wt`), exact for integers.
- Item identity: `item in list` / `list.index(item)` compare `*Item` pointers (Item has no __eq__). Objects
  (namedtuples) compare by value, but they are all distinct, so `*Obj` pointer equality is exact.

## Strings

- `bytes(arr).decode()` -> `string(arr[:])`. `.strip()` -> `PyStrip`, `.split()` -> `PySplit`,
  `x in s` -> `strings.Contains`. Python slicing on ASCII strings -> Go byte slicing, but clamp like Python
  (`s[:n]` with n > len is fine in Python).
- `re` -> Go `regexp` (compile once at package level). RE2 lacks backreferences/lookarounds; none should be
  needed. `re.findall` -> `FindAll` (list of group tuples, "" for non-participating groups), `re.search` ->
  `Search`. `[a-zA-z]` keeps its Python meaning in Go. Keep alternation order when building patterns from lists.

## Not ported

`env.debug_tiles`, `env.debug_log`, `utils.debug_log` decorators, `stats_logger` (except that Python would raise
KeyError for unknown event names, which never happens), `__str__`/`__repr__` used only for messages.
